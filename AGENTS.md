# Getting up to speed

Read [the research journal](experiments/RESEARCH_JOURNAL.md) first when starting
work in this repository. It is the primary entry point for the codebase's
research context: experiments, results, decisions, current direction and code map.
Follow its links to detailed protocols and artifacts as needed. Check live run
status before treating a journal entry's running/queued work as current.

Keep the journal updated with concise dated entries after meaningful experiments,
results or changes in research direction. Distinguish internal validation from
external test results, and completed measurements from planned work.

Also follow the repository conventions in [CLAUDE.md](CLAUDE.md).
