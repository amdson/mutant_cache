# Variant-effect model: literature survey findings

Nov 5, 2026 · @Andrew

## 

The premise: run a protein language model once on a wild-type reference, cache the input to each layer at every position; for each mutant recompute only the K mutated positions, whose queries attend to the cached reference keys/values plus each other, at O(K·L) per layer instead of O(L²); reference positions never attend to mutated ones; train a LoRA on the variant path plus a head on the mutated positions' hidden states.

## Cached-context attention and partial recomputation

No paper, preprint, repository or patent was found that combines all five components (per-layer reference cache, recompute only the mutated positions, mutated positions attend to cached reference K/V, reference side frozen, adapters/head trained on that path) in a bidirectional encoder for in-place substitutions. The components appear separately in LLM serving and in NLP encoders.

| Work | Venue | Mechanism | Components present |
| --- | --- | --- | --- |
| [Activated LoRA (aLoRA)](https://arxiv.org/abs/2504.12397), Greenewald et al., IBM | NeurIPS 2025 | LoRA on Q/K/V applied only to tokens after an invocation point. Proposition 1: keys, values and internal states before that point are identical to the base model, so base-model prefix KV is reused unchanged. SFT loss on post-invocation tokens only. | Cache, partial recompute, attend-to-cache, one-directional, adapter on active path (base frozen) |
| [Prompt Cache](https://arxiv.org/abs/2311.04934), Gim et al., Yale/Google | MLSys 2024 | Prompt schema of reusable modules; each module's per-layer K/V precomputed at fixed position IDs. Only uncached segments are run; they attend to cached module KV. Modules encoded in isolation. Has "param" placeholder slots inside modules. Training-free. | Cache, partial recompute, attend-to-cache, one-directional |
| [CacheBlend](https://arxiv.org/abs/2405.16444), Yao et al., U Chicago | EuroSys 2025 (Best Paper) | Per-chunk KV precomputed in isolation; layer-wise partial prefill recomputes \~15% of tokens (range 5–18%) selected by KV deviation at layer 1 with gradual filtering. Recomputed tokens attend to everything; others keep stale cached KV. Equivalence checked via KV-deviation metrics. Training-free. | Cache, selective recompute, attend-to-cache, one-directional in effect |
| [Block-Attention](https://arxiv.org/abs/2409.15355), Ma, Wang, Lan, Tencent | ICLR 2025 | Each non-final block computes KV with attention confined to itself; only the final block attends across blocks. RoPE reset and re-rotated. A full-attention model performs poorly under this mask, so the model is fully fine-tuned to it (\~16-point drop without). | Cache, partial recompute, attend-to-cache, one-directional, model trained to the mask (full FT, not LoRA) |
| [EPIC / LegoLink](https://arxiv.org/abs/2410.15332), Hu et al. | ICML 2025 | Chunk KV precomputed independently; only the first k≤32 tokens of each chunk plus the query are recomputed; remaining tokens' independently computed KV inserted at correct positions. Training-free. | Cache, partial recompute, attend-to-cache, one-directional |
| [KVLink](https://arxiv.org/abs/2502.16002), Yang et al., UCSB | arXiv 2025 (v4 Nov 2025) | Documents encoded independently, KV stored without RoPE; K trainable link tokens per document are the only tokens run forward, attending to preceding cached documents. Model and link tokens jointly fine-tuned, 6k steps. | Cache, partial recompute, attend-to-cache, one-directional, trained link-token path |
| [PIE](https://arxiv.org/abs/2407.03157), He et al., PKU/ByteDance | NeurIPS 2024 | Real-time code editing: prefix KV kept, only edited tokens run through the model, cached suffix keys re-rotated to new positions with one matmul. Suffix hidden states never recomputed. Authors state the semantic impact is small; prediction difference stays below 0.0002 over 64 tokens. | Cache, edited-tokens-only recompute, attend-to-cache, one-directional (measured) |
| [PatchKV](https://arxiv.org/html/2609.26219), Yang et al., Tianjin U | arXiv Aug 2026 | Interior-span edits in long contexts. New span tokens always recomputed; a predicted "dirty window" of nearby suffix tokens plus sparse high-attention distant tokens recomputed; other suffix blocks restored from cache with RoPE phase correction. States the correction cannot recover content changed by the revised causal history; measures cosine drift vs distance from the edit. | Cache, edit + neighborhood recompute, attend-to-cache, one-directional (measured) |
| [ProphetKV](https://arxiv.org/abs/2602.02579), Wang et al., HIT Shenzhen | arXiv Feb 2026 | Like CacheBlend, but selects the 20% of tokens to recompute by running the model on the short user query against the imprecise cached KV and reading query→token attention. Formalized as a residual loss. Training-free. | Cache, selective recompute, attend-to-cache, one-directional |
| [SemPIC](https://arxiv.org/abs/2607.28069), Xie et al. | arXiv Aug 2026 | LoRA-enabled "Writer" compiles each document into per-layer KV offline; a frozen "Reader" recomputes only request-specific tokens, which attend to the compiled KV. Trained by KL distillation to a full-recompute teacher; LoRA disabled at inference. | Cache, partial recompute, attend-to-cache, one-directional, adapter on the cached (context) path |
| [Incremental Transformer](https://aclanthology.org/2025.coling-main.590.pdf), Li et al. | COLING 2025 | The only bidirectional-encoder instance. RoBERTa split into lower/upper halves; original text encoded alone with projected K/V cached for m lower layers plus layer-k hidden states. New tokens' queries attend to concatenated cached K/V plus their own; the original text does not see them in those layers. Upper layers run full self-attention. Fine-tuned with distillation from a full-attention teacher. Reports 2.2 F1 drop on SQuAD1.1 at k=23. Predecessor: [DeFormer](https://aclanthology.org/2020.acl-main.411), ACL 2020. | Cache (lower layers), partial recompute (lower layers), attend-to-cache, one-directional in lower layers only; appended text, not substitutions |
| [Hydragen](https://arxiv.org/abs/2402.05099), Juravsky et al., Stanford | ICML 2024 | Decomposes attention for a batch of sequences sharing a prefix into prefix-attention computed once against the shared KV (batched as a matmul) and per-sequence suffix attention, combined with log-sum-exp. Exact, since causal masking already prevents prefix-to-suffix attention. | Cache, partial recompute, attend-to-cache, many variants against one cache; exact, not an approximation |
| [Incrementally-Computable Neural Networks](https://arxiv.org/abs/2307.14988), Sharir & Anandkumar, Caltech | arXiv 2023 / ICML 2023 workshop | Makes incremental recomputation exact by vector-quantizing activations so edits do not ripple. For attention, only altered rows/columns corresponding to conflicting positions are recomputed, O(N) per edit; batched revisions store only differing coordinates. Requires replacing softmax with an elementwise nonlinearity and training a VQ variant (VQ-OPT); shown on OPT-125M. | Cache, partial recompute, attend-to-cache, batched revisions of one base; recomputes the reference side to stay exact |
| [Eventful Transformers](https://arxiv.org/abs/2308.13494), Dutson, Li, Gupta, UW-Madison | ICCV 2023 | Video ViTs: per-layer reference copies and buffers; only tokens whose input changed beyond a threshold are pushed through token-wise ops. Keys/values of unchanged tokens come from buffers. The attention-value product is delta-updated (Eq. 8), so unchanged tokens' attention outputs do change. | Cache, changed-token recompute, attend-to-cache; propagates changes back to unchanged tokens (not one-directional) |
| [UniLM](https://arxiv.org/abs/1905.03197), Dong et al., Microsoft | NeurIPS 2019 | Single bidirectional stack with a segment mask: source tokens attend bidirectionally among themselves only; target tokens attend to all source tokens plus leftward targets. Source never attends to target. | One-directional coupling inside a bidirectional encoder |
| [Fast-dLLM](https://arxiv.org/abs/2505.22618), Wu et al. | arXiv 2025 | Block-wise approximate KV cache for bidirectional diffusion LLMs; prefix (and in DualCache, suffix) K/V cached, only the current block recomputed attending to the cache. Cached tokens are not updated until a refresh after the block completes. Justified with cosine-similarity heatmaps showing prefix key/value differences during block decoding are negligible. Training-free. | Cache, partial recompute, attend-to-cache, one-directional within a block; bidirectional model |
| [Ladder Side-Tuning](https://arxiv.org/abs/2206.06522), Sung, Cho, Bansal, UNC | NeurIPS 2022 | Frozen backbone run once; a small trainable side network reads its per-layer activations through shortcuts. Gradients never enter the backbone. | Cached backbone activations, one-directional at network level, only side path trained; not token-level |
| [XC-Cache](https://arxiv.org/abs/2404.15420), Monteiro et al., ServiceNow | arXiv 2024 | Context encoded once, top-layer states cached; decoder cross-attends via new trained cross-attention layers with a frozen base. Query-independent context named as a quality cost. | Frozen reference, trained adapters; final-layer states only, not per-layer KV |
| [TokenTune](https://arxiv.org/abs/2501.18824), Simoulin et al., Meta | arXiv 2025 | Backpropagates only through selected token positions, combined with LoRA. Forward pass remains full. | Gradient restricted to a token subset |
| [AttriBoT](https://arxiv.org/abs/2411.15102), Liu, Kandpal, Raffel | ICLR 2025 | Leave-one-out context attribution: caches KV from the full pass and reuses it for the prefix before the removed source (lossless by causality, \~2× FLOP saving), plus hierarchical attribution and proxy models. | Cache, attend-to-cache; recomputes everything after the ablated source, lossless |
| [Prefix-tuning](https://aclanthology.org/2021.acl-long.353), Li & Liang | ACL 2021 | Per-layer prefix K/V fixed with respect to the input; no token updates them. | One-directional coupling; the fixed set is small and trainable, the large set recomputed per input |

Also found: [KVLINK](https://arxiv.org/pdf/2502.16002) and [C²KV](https://arxiv.org/pdf/2607.17715) precompute and recombine KV caches of independently encoded segments in decoder LLMs.

No patent was found claiming cached reference activations plus variant-only recompute plus a one-way mask. Searches covered Google Patents, Justia and patentlyze with combinations of {variant, mutation, reference sequence, language model, cached, key, value, attention mask, mutated positions} and company names. DeepMind US 2026/0341404 A1 (filed Apr 2025, PCT Oct 2023; Avsec, Novati, Cheng) covers AlphaMissense-style MSA row/column attention with the mutated position masked, with no caching or partial recompute in the summary. Illumina US 2019/0318806 is a CNN variant classifier.

## Partial recomputation in in-silico mutagenesis (CNNs)

[fastISM](https://academic.oup.com/bioinformatics/article/38/9/2397/6541633) — Nair, Shrikumar, Schreiber, Kundaje, *Bioinformatics* 2022. Computes intermediate activations once per unperturbed reference and caches them; for each mutation recomputes only positions whose receptive field is affected, reusing cached values elsewhere, falling back to standard ISM once a dense layer is reached. Recomputation is exact: unaffected positions provably equal the reference. No attention. The paper treats transformers as the limiting case: Enformer's transformer layers have a full receptive field, so fastISM accelerates only its initial convolutions — 2.3× speedup, rising to 5.5× when transformer layers were cut from 11 to 4. No attention-specific optimization is proposed. [Code](https://github.com/kundajelab/fastISM).

[Yuzu](https://www.biorxiv.org/content/10.1101/2021.11.08.467498.full.pdf) — Schreiber, Nair et al., bioRxiv 2021 / *Bioinformatics* 2022. Propagates sparse delta tensors through convolutional layers via compressed-sensing probes; tested on DeepSEA, Basset and BPNet. Transformers mentioned only as a possible extension with sparse attention.

[TISM](https://www.biorxiv.org/content/10.1101/2023.11.10.566588.full.pdf) — Sasse et al., bioRxiv 2023 / *iScience* 2024. First-order Taylor approximation to ISM from one forward and backward pass; gradient differences approximate ISM at roughly 0.7 correlation, with 25× to 8000× speedup. CNN only. A different approximation axis: linearize the model around the reference rather than truncate attention flow.

## Protein methods that amortize one reference forward pass

No protein paper was found that caches per-layer reference K/V and partially re-runs the trunk. The published approaches run the backbone once on the wild type and read all substitutions off the resulting features; mutant sequences never enter the encoder.

[Mutate Everything](https://arxiv.org/abs/2310.12979) — Ouyang-Zhang, Diaz, Klivans, Krähenbühl, NeurIPS 2023. Backbone (AlphaFold, or ESM-2 in ablation) runs once per wild type; each position's final features are expanded into 20 mutation representations as z(μ) = f\_t(x\_p) + h\_t, a sequence-dependent projection plus a learned amino-acid embedding; a linear head gives ΔΔG. Multi-mutants are the sum of single-mutation latents through a small MLP, with a learned residual for doubles, parallelized by outer-sum and gather. All singles and doubles for a 317-residue protein in \~12.1 s on an A100. The backbone is fine-tuned, not frozen: freezing changed Spearman on S669 from 0.56 to 0.48. Two-stage training (singles, then singles+doubles), Huber loss.

[StabilityArc](https://arxiv.org/abs/2610.00742) — Feller, Ellington, Wilke, UT Austin, arXiv 2610.00742, v1 30 Sep 2026, v2 15 Oct 2026. Frozen ESMC-600M wild-type residue embeddings → shared 4-layer pre-norm transformer (RoPE, 8 heads, d=256) → linear head emitting an L×20 matrix in one forward pass. Doubles are the sum of singles plus a symmetric learned epistasis residual conditioned on substituted-amino-acid embeddings, using sequence separation and contact probabilities read from the frozen ESMC attention maps. Trained on 66 ProteinGym stability assays, 134,794 variants (68,855 singles, 65,939 doubles), capped at 40k per assay. 66 leave-one-protein-out evaluations: macro Spearman 0.7134 vs 0.6526 for ProSST-2048, the best zero-shot baseline; as a Kermut prior, 0.8280 vs Kermut's 0.8167. [Code](https://github.com/AaronFeller/StabilityArc), [weights](https://huggingface.co/aaronfeller/StabilityArc).

[SPURS](https://www.biorxiv.org/content/10.1101/2025.02.13.638154v2.full) — bioRxiv 2025.02.13.638154, *Nature Communications* 2025 (s41467-025-67609-4). An adapter with cross-attention pulls ProteinMPNN structural features into frozen ESM2-650M embeddings, predicting ΔΔG for all 20 substitutions at every position. Trained on 272,721 single mutants across 298 proteins from Tsuboyama (ThermoMPNN 8:1:1 split), plus 122,278 doubles for an epistasis extension. >25% identity filtered against test sets. \~9.9M trainable parameters, a 98.5% reduction vs full fine-tuning. All single mutants in one forward pass; \~20 s for 118 proteins on one A40; \~30 min for human-proteome site saturation. Beat or matched baselines on 7 of 8 independent comparisons. [Code](https://github.com/luo-group/SPURS).

[Composable epistasis-aware mutation atlas](https://www.biorxiv.org/content/10.64898/2026.09.24.753701v1.full) — Wang, Yu, Yang, Shi, Yu, Hu, Xu, Gong, bioRxiv 2026 (doi 10.64898/2026.09.24.753701). Frozen ESMC/ESM3 embeddings → Evoformer + structure module; an SE(3)-Transformer encodes the wild type once into a single-mutation score tensor S (L×20) and an epistasis tensor U. Per mutant, entries are retrieved and combined by permutation-invariant summation scaled by mutation order through a shared MLP. States the computation shifts from large candidate libraries to a single reference protein, with inference time nearly constant in library size.

[Venus-MAXWELL](https://www.biorxiv.org/content/10.1101/2025.05.30.656964.full.pdf) — Yu et al., bioRxiv 2025.05.30.656964, NeurIPS 2025. A PLM (ESM-IF, ProSST, ESM-1b, ESM2 or ESM-1v) whose output log-probabilities are turned into a ΔΔG landscape. The wild-type sequence goes through the PLM once; an element-wise product with the one-hot matrix, summation over amino acids, and subtraction of the replicated wild-type vector yields the full n×|A| mutation matrix in one forward pass. A two-layer SELU MLP maps log-probability scores to ΔΔG; loss combines a negative-Pearson ranking term with MSE (λ=0.1), with masks for sparse measurements. The entire PLM is fine-tuned; LoRA is not used. Train226K from cDNA272K: 573 proteins, 239,408 mutations, \~418 per protein; Test12K has 12,443 mutations across 308 proteins. Training sequences with ≥30% identity to any test sequence removed; average train/test TM-score \~0.3. Test12K per-protein Spearman 0.517 (ESM-IF) vs ThermoMPNN 0.508 and zero-shot ESM-IF 0.375; 0.479 for ProSST; average +0.143 over zero-shot. 20,050 mutants/s (ESM-IF) and 85,471 mutants/s (ProSST) vs 2,088 for ThermoMPNN; \~41 s/epoch on Train226K; Spearman 0.501 with 90% of training mutants removed. The introduction cites "over 10 times faster" inference while the conclusion claims "three orders of magnitude."

[VespaG](https://academic.oup.com/bioinformatics/article/40/11/btae621/7907184) — Marquet, Schlensok, Abakarova, Rost, Laine, *Bioinformatics* 40(11), 2024. Frozen ESM-2 wild-type embeddings through a small FFN (one 256-unit hidden layer, \~660k parameters) emitting 20 substitution scores per residue, distilling GEMME scores over 39M mutations. Authors state they optimized prediction speed by circumventing the masked token reconstruction task. Whole proteomes in under 30 min on a laptop.

[ThermoMPNN](https://www.biorxiv.org/content/10.1101/2023.07.27.550881.full.pdf) — Dieckhaus, Brocidiacono, Randolph, Kuhlman, *PNAS* 121(6), 2024. ProteinMPNN frozen as a feature extractor; decoder embeddings from each layer at the mutated residue only, concatenated with the wild-type sequence embedding, through a light-attention block and MLP, predicting ΔΔG for each possible amino acid, normalized by subtracting the predicted wild type at that position.

[Pseudo-perplexity in One Fell Swoop](https://arxiv.org/html/2407.07265v1) — Kantroo, Wagner, Machta, arXiv 2407.07265, 2024. One unmasked ESM-2 650M pass; an ensemble of 8 MLPs on a frozen encoder maps each position's final embedding to a 20-way approximation of the masked profile P(r\_i | S\_−i), removing the L masked passes needed for pseudo-log-likelihood. Trained on Swiss-Prot ≤700 aa clustered at 50% identity, with >50%-identity ProteinGym references excluded. The saving is over the L masked passes within a sequence, not across mutants.

[How to make the most of your masked language model for protein engineering](https://arxiv.org/html/2603.10302v1) — McCarter, Bhattacharya, Ober, Elliott, BigHat, arXiv 2603.10302, 2026. Uses the wild-type-marginal trick in beam search: approximate pseudo-log-likelihoods for all 1-substitution neighbors come free from a template pass; the exact conditional at the mutated position comes from a masked pass on the child, with template conditionals reused elsewhere. Logit-level reuse only; no activation caching.

[Wild-type marginal scoring](https://www.biorxiv.org/content/10.1101/2021.07.09.450648v2.full) — Meier et al., ESM-1v, NeurIPS 2021. The main text defines only the masked marginal, where the input is masked at every mutated position, and reports it beats the other three strategies; the wild-type marginal, mutant marginal and pseudo-likelihood definitions are in Appendix A, which could not be retrieved from the HTML. Wild-type marginal reuses output logits of one pass.

[esm-variants](https://github.com/ntranoslab/esm-variants) — Brandes et al., ntranoslab. Scores all possible missense mutations genome-wide. The README documents only the CLI and defers method details to the paper's Supplementary Methods; no statement about pass counts or caching. The standard masked-marginal route needs L masked passes to cover all 20·L single mutants.

## Mutated-position heads, delta embeddings, mutant-path adapters

[ESM-Effect](https://www.biorxiv.org/content/10.1101/2025.02.03.635741v1.full) — Glaser & Brägelmann, bioRxiv 2025.02.03.635741, ICLR 2025 workshop. A mutation-position regression head reads the mutant embedding at the mutated position, combined linearly with the wild-type embedding at the same position; reports mean-pooled heads do worse (PTEN). 10 of 12 ESM2 layers frozen, last two trained. LoRA was tested and rejected in favor of partial fine-tuning, stated as comparable performance while avoiding LoRA's hyperparameter tuning. Scaling analysis over ESM-2 8M→3B; the shipped model uses 35M. States no obvious performance improvements emerge with larger models across all DMS uniformly, and that scaling laws do not carry over to DMS fine-tuning. "ESM-Effect Speed" collects layer-10 embeddings in the first epoch and reuses them in later epochs, an 8.4× speedup — caching per-variant activations across epochs, with no saving in epoch 1 or at inference. 6.7× faster training than PreMode. No GPU type, GPU-hours or peak memory reported.

[ESM-MSR](https://www.biorxiv.org/content/10.64898/2026.06.04.730231) — Reeves & Kalyaanamoorthy, Waterloo, bioRxiv 10.64898/2026.06.04.730231, 2026. Two LoRA adapters on frozen ESM3-small-open (\~1.4B), one for the wild-type perspective and one for the mutant perspective, adding <1.3% trainable parameters. Wild-type logits computed once per protein; the mutant path is a full forward pass per variant; score from logit differences at mutated positions. Trained on 521,154 mutations from Tsuboyama after preprocessing. Held-out Megascale test of 43,700 mutants (32,968 single, 10,732 double) across 36 domains; SOTA on Human Domainome 1 abundance (ρ\_avg 0.573); top performance on 4 of 10 external thermostability benchmarks. Reported weaknesses: negative-epistasis ranking, cysteine selection bias, loses to Mutate Everything and Rosetta on PTMUL. No activation caching or partial recompute. [Code](https://github.com/SKTeamLab/esm-msr).

[MutaPLM](https://arxiv.org/html/2410.22949v1) — Luo, Nie, Hong, Zhao, Zhou, Nie, NeurIPS 2024. h\_Δ = h\_mt − h\_wt over ESM-2-650M per-residue features; a delta encoder cross-attends 32 trainable queries over h\_Δ to a fixed latent z\_Δ; a symmetric decoder cross-attends from h\_wt to z\_Δ and rebuilds h\_mt = h\_wt + h\_Δ. Requires a full mutant forward pass to obtain h\_mt.

[pLM-SAV](https://academic.oup.com/bioinformaticsadvances/article/6/1/vbag195/8735225) — *Bioinformatics Advances* 6(1):vbag195, 2026. Mutant-minus-wild-type embedding difference into a pathogenicity classifier. Requires a full forward pass per mutant.

[Hint tokens](https://academic.oup.com/nargab/article/7/3/lqaf128/8266003) — Li, Perez, Giannakoulias, Petersson, *NAR Genomics and Bioinformatics* 7(3):lqaf128, Sept 2025. Inserts \[MUT\_start\] and \[MUT\_end\] tokens around each mutated residue in the otherwise unchanged mutant sequence, then fine-tunes ProtBERT/ProtT5/ESM2. No caching, no attention masking; full mutant passes.

[ConFit](https://www.biorxiv.org/content/10.1101/2024.02.11.579859.full.pdf) — Zhao, Zhang, Luo, RECOMB 2024. LoRA-based contrastive fine-tuning of a PLM for fitness; low-N, per-protein, not multi-assay.

[ProteinTTT](https://arxiv.org/abs/2411.02109) — "One Protein Is All You Need," CTU/SNU/MIT/Qminers. Customizes a pretrained PLM to one target protein at a time by masked-LM on that protein's sequence alone, selecting the highest-confidence checkpoint; parameters reset to pretrained weights before each new target. Adapts the backbone through LoRA with SGD and gradient accumulation while the downstream head stays frozen (parameter-free log-likelihood scoring). ProteinGym average Spearman over 186 proteins: ESM2-650M 0.4139→0.4153, ProSST (K=2048) 0.5068→0.5087, ProGen2-small 0.3255→0.3591. Zero-shot only.

[InstructPLM-mu](https://arxiv.org/pdf/2510.03370) — Xu, Shi, Lang, Cui, Zhang, Chen, Qiu, Heng, arXiv 2510.03370, Oct 2025. Multimodal structure-injected fine-tuning of ESM2, evaluated zero-shot on ProteinGym (201 assays, masked marginals). ESM2 35M/150M/650M fine-tuned; 3B as a sequence-only baseline. Compares full FT (100%), LoRA+Adapter (5–10%, r=32 α=256), Adapter-only (\~1%). 4× A100 for all experiments. Adapter-only improves with size (0.358 → 0.407 → 0.45 for 35M/150M/650M), but LoRA+Adapter and full FT gains stagnate or become unstable on larger backbones. Sequence-only baselines: 650M 0.428, 3B 0.421. The "1 hour" in the title appears only in the title and Fig. 1 caption with no hardware, step count or configuration given. Token-wise concatenation doubles sequence length.

[VESM](https://huggingface.co/ntranoslab/vesm) — Dinh, Jang, Zaitlen, Ntranos. VESM\_35M/150M/650M on ESM-2; VESM3 fine-tuned from ESM3-Open. Co-distillation of an ESM ensemble, not labeled variant training. MIT license except VESM3 (non-commercial).

[SAE feature steering](https://www.biorxiv.org/content/10.64898/2026.05.12.724472v1.full) — Wang, Yuan, Vasilakos, He, Ren, bioRxiv 10.64898/2026.05.12.724472, 2026. Sparse autoencoder on frozen ESM-3 1.4B / ESM-2 650M; the multi-task variant (ESM2-SAE-Cross) trains shared and task-specific gates jointly across VenusMutHub categories. Precomputed embeddings in LMDB, dynamic batching. Code availability not stated.

## Reported compute, memory and throughput figures

No paper reports GPU-hours for supervised DMS fine-tuning at 3B. The figures below are the closest published numbers.

[ESME / iScience 2025](https://www.biorxiv.org/content/10.1101/2024.10.22.619563v1.full) — FlashAttention, a Partition-Attention scheme for variable-length batches, activation checkpointing, ZeRO-Offload with CPU-Adam, 8-bit and 4-bit quantization, LoRA.

- One epoch over 571,609 Swiss-Prot proteins on 4× A6000: \~0.04 h (8M), \~1.1 h (650M), \~3.4 h (3B).
- 3B LoRA ≈ 3.4 h/epoch, 12.5% faster than full training.
- Activation checkpointing: 650M \~10→8 GB; 3B \~35→28 GB. ZeRO-Offload saves \~39%.
- 15B LoRA fine-tuning feasible at 33 GB; 15B full training infeasible even with all optimizations at batch size 4.
- Inference: 3–10× runtime reduction (up to 16× claimed), up to 8× memory reduction; 3B at \~5.6 GB for 300–400 residues; up to 100k tokens without OOM.
- Quantization at 3B: 4-bit and 8-bit reach 41% and 80% of unquantized memory; at 15B, 33% and 63%.
- Full UniRef50 training estimates: 150M \~33 days, 650M \~309 days.

[Shao 2026](https://www.biorxiv.org/content/10.64898/2026.08.10.744024v1.full) — single H200 (143 GB), inference only.

[ProteinGym](https://papers.nips.cc/paper_files/paper/2023/file/cac723e5ff29f65e3fcbb0739ae91bee-Paper-Datasets_and_Benchmarks.pdf) — Notin, Kollasch, Ritter, van Niekerk, Paul, Spinner, Rollins, Shaw, Orenbuch, Weitzman, Frazer, Dias, Franceschi, Gal, Marks, NeurIPS 2023 Datasets & Benchmarks. [Repo](https://github.com/OATML-Markslab/ProteinGym).

Leaderboard numbers, quoted in Guan et al. 2026 Table 3: Kermut 0.745 Spearman / 0.413 MSE; ProteinNPT 0.741 / 0.441; Tranception Embeddings 0.681 / 0.518; MSA Transformer Embeddings 0.670 / 0.529; ESM-1v Embeddings 0.614 / 0.603. Per-scheme from Kermut's own paper (217 substitution assays): Kermut 0.744 random / 0.633 modulo / 0.610 contiguous, avg 0.662; ProteinNPT 0.730 / 0.564 / 0.547, avg 0.613.

The GitHub README states that code for training and evaluating supervised models lives in the ProteinNPT repository, and that release v1.3 added 16 zero-shot substitution baselines including ESM3, ESM C, ProGen3 and xTrimoPGLM. No 2025 or 2026 supervised additions are listed. Kermut is not mentioned on the README. Results are aggregated by UniProt ID so proteins with many assays do not bias results, and by functional category. The page does not describe a cross-protein evaluation setting for the supervised benchmark.

Supervised split schemes, 5 folds each: `random` (mutations assigned to folds at random), `contiguous` (the sequence split contiguously along its length into five position segments), `modulo` (positions assigned by position mod 5). The stated purpose of the position-based schemes is to quantify extrapolation to positions unseen at training time. All three are within-protein. The paper states cross-protein and cross-family generalization is out of scope.

Normalization across assays: essentially none. Per the [reference-file schema](https://huggingface.co/datasets/ICML2022/ProteinGym/blob/main/reference_files_description.md), each assay carries `raw_DMS_phenotype_name` (which raw column was taken, untransformed), `raw_DMS_directionality` (1 if higher raw value means higher fitness, −1 otherwise; the released `DMS_score` is sign-flipped so higher always means fitter — the only harmonization step), and `DMS_binarization_cutoff_ProteinGym` with `DMS_binarization_method` set to `manual` or `median`, producing `DMS_score_bin`. Comparability is handled at the metric level: Spearman is primary, described as the most generally appropriate metric given the often non-linear link between function and fitness, with AUC, MCC, NDCG and Top-10%-recall supplementing it because rank correlations may not be optimal for bimodal assays. Aggregation is a corrected average: metrics averaged within functional groups (stability, binding, expression, activity, organismal fitness), then those group averages averaged with equal weight.

ProteinGym ships supervised DMS model scores as downloads (3.3 GB substitutions, 215 MB indels); the repo README does not name the models.

[FLIP](https://www.biorxiv.org/content/10.1101/2021.11.09.467890.full.pdf) — Dallago, Mou, Johnston, Wittmann, Bhattacharya, Goldman, Madani, Yang, NeurIPS 2021 Datasets & Benchmarks. Split names:

- GB1 (5): `1-vs-rest`, `2-vs-rest`, `3-vs-rest` (train on up to n-mutants, test higher order), `low-vs-high` (train ≤ WT fitness, test > WT), `sampled` (random 80/20 — the paper states it overestimates performance and is for discussion only).
- AAV (7): `mut-des`, `des-mut`, `1-vs-rest`, `2-vs-rest`, `7-vs-rest`, `low-vs-high`, `sampled`.
- Thermostability/meltome (3), the only cross-protein tasks in FLIP: `mixed`, `human`, `human-cell`. All three use MMseqs2 clustering at 20% sequence identity, \~80% of clusters to train, cluster representatives from the remaining 20% to test. `mixed` spans 13 species.

[FLIP2](https://icml.cc/virtual/2026/poster/63684) — Didi, Alamdari, Lu, Wittmann, Johnston, Amini, Madani, Czeneszew, Dallago, Yang, ICML 2026 (oral + poster); bioRxiv 10.64898/2026.02.23.707496. ## Cross-assay label normalization and calibration

**Synonymous/nonsense anchoring.** [GSK NLR](https://arxiv.org/html/2405.06729v1) normalizes each MaveDB score set by log-transforming, then linearly rescaling so the mean synonymous score maps to 0 and the mean nonsense score to −1, with the synonymous−nonsense gap as the denominator; values capped to \[−2, 2\]. Each assay uses its own control means. Inclusion filter: ≥1 synonymous, ≥1 nonsense, >50 missense variants, giving 103 datasets over 30 proteins. Duplicate variant scores across assays are averaged. Model log-odds-ratio matrices are min-max scaled to \[−2, 2\] during training only. Loss is MSE on the normalized score.

**Anchor with percentile fallbacks.** [StructGuy](https://www.biorxiv.org/content/10.64898/2025.12.01.691563.full.pdf) — bioRxiv 10.64898/2025.12.01.691563, Dec 2025. Builds a MAVE gold standard of 287 proteins and 582,307 single amino-acid variants pooled from MaveDB, ProteinGym and Domainome, rescaling every experiment so 1 = wild type and 0 = complete loss of function. The neutral value is the mean of synonymous variants where available, otherwise the mode of the score distribution. Score orientation is inferred from proline and alanine substitution baselines, or the overall mean where unavailable. Strong-detrimental and beneficial reference points are the leftmost and rightmost percentiles of the distribution. Filters: drop experiments on proteins <50 aa, covering <40% of the protein, or with normalized SD <0.25. Multiple score sets within one experiment averaged per variant; separate experiments on the same protein kept as separate entries.

**Per-assay calibration curve.** [Schulze, Blaabjerg, Cagiada, Lindorff-Larsen](https://www.biorxiv.org/content/10.1101/2025.04.02.646878.full.pdf) — bioRxiv 2025.04.02.646878; also published as *Protein Science* 35(4):e70526, 1 Apr 2026, doi [10.1002/pro.70526](https://onlinelibrary.wiley.com/doi/10.1002/pro.70526), [PubMed 41795207](https://pubmed.ncbi.nlm.nih.gov/41795207/). Pools six VAMP-seq abundance datasets (PTEN, TPMT, CYP2C9, NUDT15, ASPA, PRKN; \~32,000 single substitutions), anchored 0 = nonsense-like, 1 = WT-like. Heterogeneity is absorbed by a per-dataset standard curve: a small MLP with one hidden layer and two tanh nodes, fit on low-throughput validation variants, mapping the shared latent prediction to that experiment's observed scale. Predictions pass through the frozen standard curve during training; loss is MAE. Evaluation is leave-one-protein-out across the six proteins, with standard-curve-fitting variants excluded from scoring. The published abstract states that experimental method and library composition shift variant scores between experiments, and that mapping abundance to the VAMP-seq readout in a dataset-specific way during training improved the learned model and allowed prediction on an interpretable scale.

**Formal measurement-process model.** [MAVE-NN](https://doi.org/10.1186/s13059-022-02661-7) — Tareen, Kooshkbaghi, Posfai, Ireland, McCandlish, Kinney, *Genome Biology* 23:98, 2022. Factorizes each measurement into a deterministic genotype-phenotype map producing a latent phenotype φ, and a probabilistic assay-specific measurement process p(y|φ), fit jointly by regularized NLL. In GE mode (continuous readouts) the measurement process is a monotonic global-epistasis nonlinearity g(φ) built as a sum of tanh sigmoids, designed to model background and saturation, plus a noise model (Gaussian, Cauchy or skewed-t, each homo- or heteroscedastic); monotonicity can be relaxed. In MPA mode (binned/sort-seq readouts) a softmax over bins makes no functional-form assumption. Gauge fixing standardizes φ to mean 0, SD 1 on training data. Stated limitation: single-mutant-only data cannot identify the nonlinearity, so some double mutants are needed.

**Per-assay min-max.** [PRIMO](https://arxiv.org/html/2512.02315v1) min-max normalizes raw DMS fitness values within each assay. Each sample carries a categorical property-type ID embedded as an input token — a property-type token (5-way), not a per-assay identifier. Training draws sets of N=32 sequences from a single assay at a time; fitness labels masked 33% of the time, sequence spans 20%. Loss is a pairwise preference loss over masked samples, σ(score difference) penalized when the ordering disagrees.

**Per-assay z-score.** [Metalic](https://www.arxiv.org/pdf/2410.08355) standardizes all fitness values by subtracting the mean and dividing by the standard deviation per task. Loss is binary cross-entropy over all ordered query pairs via σ(v\_i − v\_j); support-set samples excluded from the loss. No explicit assay token; conditioning is implicit via the support set, whose fitness values are linearly projected into embedding space, with query fitness slots sharing a learned embedding.

**Listwise ranking.** [FSFP](https://arxiv.org/pdf/2402.02004) — Zhou, Zhang, Yu, Li, Hong, Tan, *Nature Communications* 15, 2024; arXiv 2402.02004. Uses ListMLE (likelihood of the correct permutation) rather than regression, arguing ranking is not forced to fit exact label values. Meta-transfer learning with auxiliary tasks chosen by PLM-embedding cosine similarity to the target protein: the two most similar ProteinGym proteins' DMS datasets, plus one task of GEMME pseudo-labels on candidate mutants of the target. Only top-2 used because protein similarities in ProteinGym are low overall. Evaluated on the 87-assay ProteinGym substitution benchmark with 20→100 training mutants, 5 seeds.

**No normalization, pairwise loss per assay.** [SynFit](https://www.biorxiv.org/content/10.64898/2026.05.21.726972v1.full.pdf) applies no label normalization. A Bradley-Terry pairwise contrastive loss per objective learns within-assay relative order, plus a KL penalty against the frozen pLM's wild-type residue distribution. Shared encoder with one prediction head per assay; two-stage training (heads trained with the trunk frozen, then heads frozen and the trunk trained jointly); per-objective losses combined as a weighted sum (equal 1/M or tuned).

**Rank fusion across assays.** [ESMRank](https://www.biorxiv.org/content/10.64898/2026.02.26.708185v1.full) does not regress raw scores. Within-assay rankings on shared variants are aligned and fused with Reciprocal Rank Fusion into a consensus "variant soundness" score on a common scale, using the 581 overlapping score sets as anchors; the model optimizes relative ordering within each protein rather than absolute effect sizes.

**Masked-target imputation for ragged matrices.** [ProteinNPT](https://proceedings.neurips.cc/paper_files/paper/2023/file/6a4d5d85f7a52f062d23d98d544a5578-Paper-Conference.pdf) accepts multiple target columns at once plus auxiliary labels (correlated inputs excluded from the loss — in the final model, MSA-Transformer zero-shot scores). Missing target values are masked in the input, described as an implicit imputation scheme. Labels get only standard scaling on the input targets.

**Percentile binarization.** [CPT-1](https://link.springer.com/article/10.1186/s13059-023-03024-6) binarizes each protein's DMS scores at the top 40% and bottom 40%, discarding the middle 20%, because score distributions differ across proteins; reported stable across thresholds. Features scaled to unit SD with each training protein weighted equally so large proteins do not dominate; missing features KNN-imputed. Per-protein models averaged as a way to adjust for batch effects.

**Variance-normalized metric.** [Badrinarayanan et al.](https://arxiv.org/html/2510.20943v1) use per-source StandardScaler on targets and NMSE (MSE divided by the variance of true values) to compare across scales and units.

**Normalization-to-anchor for domain data.** [VEFill](https://www.biorxiv.org/content/10.1101/2025.05.14.653991v2.full) normalizes raw scores so 0 is the median nonsense-mutation score and 1 is wild type, without clipping. Training uses a single standardized assay, limiting cross-assay heterogeneity; performance is weaker on external activity-based assays and no separate calibration step is described.

**Reporting standard.** [Minimum information and guidelines for reporting a Multiplexed Assay of Variant Effect](https://arxiv.org/pdf/2306.15113) — Claussnitzer, Parikh, Wagner (equal first), Arbesfeld, Bult, Firth, Muffley, Nguyen Ba, Riehle, Roth, Tabet, Bolognesi, Glazer, Rubin, arXiv 2306.15113. Requires depositing scores before normalization or imputation, alongside raw counts, normalized/imputed scores and error estimates. Mandated reuse fields include versioned target sequence (RefSeq/Ensembl/UniProt), variant-generation and delivery method, model system (NCBI Taxonomy + Cell Line Ontology), assay readout as an OBI ontology term, sequencing method, environmental variables, VRS variant representation, disease context (Mondo/OMIM), and software versions with code DOI. The standard specifies nothing about normalization, controls, direction or dynamic range.

## Split protocols, leakage, and bias tests

**Leakage taxonomy.** [The evaluation of tools used to predict the impact of missense variants is hindered by two types of circularity](https://doi.org/10.1002/humu.22768) — Grimm, Azencott, Aicheler, Gieraths, MacArthur, Samocha, Cooper, Stenson, Daly, Smoller, Duncan, Borgwardt, *Human Mutation* 36(5):513–523, 2015. Type 1: test variants overlap the tool's training variants. Type 2: test and training variants come from the same protein, so a majority vote over that protein's training labels predicts the test labels without sequence-level generalization. [StructGuy](https://www.biorxiv.org/content/10.64898/2025.12.01.691563.full.pdf) applies this taxonomy to ProteinGym and states that the supervised track tests mutations in proteins already seen in training, so it does not measure generalization. StructGuy enumerates four leakage levels: identical mutations shared across splits; different substitutions at the same position split across train/test; different positions in the same protein split across train/test (type 2); and homologous proteins across train/test.

**Identity-binned re-split.** [StructGuy](https://www.biorxiv.org/content/10.64898/2025.12.01.691563.full.pdf) uses DataSAIL for splitting and MMseqs2 for identity, binning ProteinGym proteins by maximum sequence identity to the training set at 35%, 50%, 95% and 100%. The <35% bin (167 of ProteinGym's 217 MAVEs) is the designated leakage-free benchmark. Only single amino-acid variants kept. The training set was itself split into four DataSAIL bins with similar proteins co-located. The clinical substitutions benchmark was used but not re-split, so leakage there remains.

**Leave-one-protein-out.** [CPT-1](https://link.springer.com/article/10.1186/s13059-023-03024-6) trains on DMS from five human proteins and predicts each by a model trained on the other four; the 13 ProteinGym datasets are predicted by the model trained on all five; ClinVar evaluation is restricted to genes never seen in training. Feature selection itself used leave-one-protein-out CV. For the REVEL comparison they removed genes whose clinical annotations existed when REVEL was trained (giving 407 genes) and excluded any predictor previously trained on clinical or functional assay data. They note homology filtering of the splits is not described, being inherited from EVE and ESM-1v. [Code](https://www.github.com/songlab-cal/CPT).

**Cross-dataset homologue forcing.** [ThermoMPNN](https://www.biorxiv.org/content/10.1101/2023.07.27.550881.full.pdf) — Dieckhaus, Brocidiacono, Randolph, Kuhlman, *PNAS* 121(6), 2024. Megascale curation: April 2023 release, drop ΔΔG marked unreliable, drop indels and multi-mutants, drop data from perturbed-WT measurements, giving 272,712 mutations across 298 proteins. Splits use MMseqs2 at 25% identity per dataset; clusters with homologues across datasets are forced into the respective training sets so no test protein has a homologue in training; remaining clusters 80/10/10 (Megascale 239/31/28 proteins; FireProt 57/15/28); FireProt proteins with >250 data points always placed in train. A separate homologue-free FireProt set of 89 proteins evaluates Megascale-only models. Notes the proteolysis assay's \~5 kcal/mol range is why Megascale-trained models struggle at large ΔΔG, while FireProt extends to ±10 kcal/mol, with 96.7% of FireProt mutations inside the Megascale range.

**Documented leakage instance.** [PRIMO](https://arxiv.org/html/2512.02315v1) audits Metalic's ProteinGym split and reports training proteins at 99–100% identity to test proteins, naming BLAT\_ECOLX and RL40A\_YEAST; RL40A\_YEAST's zero-shot score rose from 0.30 to 0.74 with the leak present. PRIMO's own evaluation uses a held-out ProteinGym subset designed to control overlap at the protein level, plus a natural-evolution benchmark of three assays (chorismate mutase, Rubisco, PPAT) testing extrapolation far from the wild type.

**Site-level leakage and the site-means baseline.** [Intrinsic dataset features drive mutational effect prediction by protein language models](https://www.biorxiv.org/content/10.64898/2026.03.08.710389v1.full) — Vieira, Lin, Wilke, 2026, doi 10.64898/2026.03.08.710389. States much of pLMs' apparent DMS performance comes from how fitness variation is distributed across sites rather than substitution-specific learning: a naive site-means predictor matches or beats supervised transfer learning on many datasets, especially viral ones. Introduces RVSM (relative variability of site means) and FHVS (fraction of highly variable sites, threshold 0.7); performance rises with RVSM and peaks at intermediate FHVS (\~0.25–0.5). RVSM and FHVS explained up to \~61% of the variance in Kermut's Spearman under pooled splits, and the paper states that the better a model performs, the more its performance is explained by these site-variability features. Pooled splits place mutations from the same site in both train and test, inflating performance; site-stratified splits sharply reduce R² for all models. Pooled splits gave the best scores for every ProteinGym model tested, reproducing pooled > modulo > contiguous. Models trained only on single mutants predicted double mutants poorly; an embedding-based ESM C model usually beat a simple additive baseline but absolute performance stayed low. LoRA fine-tuning improved R² without changing the conclusion. The paper does not test pooled multi-assay training or cross-assay transfer, and does not analyze label-scale heterogeneity.

**Antisymmetry and direction-bias tests.** [Self-consistency test reveals systematic bias in programs for prediction change of stability upon mutation](https://doi.org/10.1093/bioinformatics/bty340) — Usmanova, Bogatyreva,Ariño Bernad, Eremina, Gorshkova, Kanevskiy, Lonishin, Meister, Yakupova, Kondrashov, Ivankov, *Bioinformatics* 34(21):3653–3658, 2018. Measures bias as a function of the number of mutations using a self-consistency test based on reciprocity of each mutation's effect, ΔΔG(A→B) = −ΔΔG(B→A), requiring only structures and no experimental stability data. Found inherent bias in FoldX, Eris, Rosetta and I-Mutant; Modeller relaxation substantially reduced FoldX's bias.

[S669](https://iris.unito.it/retrieve/e27ce433-fde9-2581-e053-d805fe0acbaa/bbab555.pdf) — Pancotti, Benevenuta, Birolo, Alberini, Repetto, Sanavia, Capriotti, Fariselli, *Briefings in Bioinformatics* 2022, doi 10.1093/bib/bbab555. Construction: 900 variants from ThermoMutDB v1.3 restricted to proteins with <25% sequence identity to S2648 and VariBench, the sets existing tools were trained on; 231 dropped for annotation inconsistencies (kinetics or binding free energies, multi-variants), giving 669; ΔΔG corrected for \~20% where the sign was incoherent or the value imprecise. Direct-variant Pearson on this external set is \~0.2–0.5. Datasets are skewed toward destabilizing variants, so 669 reverse variants are added, giving S669+ at 1,338 total. Non-antisymmetric tools show strong bias on reverse variants: mCSM δ = −0.85, PoPMuSiC δ = −0.69, vs antisymmetric INPS-Seq and ACDC-NN-Seq at δ ≈ 0 and r\_d−r ≈ −1. Stabilizing variants are harder and all tools compress predictions toward zero. Reverse structures were Rosetta/Robetta models, with experimental-vs-modelled agreement PCC \~0.995. ThermoMPNN evaluated on Ssym direct vs inverse: PCC 0.72 vs 0.60; its architecture subtracts predicted mutant from predicted wild-type ΔΔG at the same position.

**Homology leakage in genome-trained models.** [Detecting and avoiding homology-based data leakage in genome-trained sequence models](https://www.biorxiv.org/content/10.1101/2025.01.22.634321v1.full) — Rafi, Kiyota, Yachie, de Boer, bioRxiv, posted 24 Jan 2025. Shows chromosome-based splits leak homologous sequences: in a \~220k × 200 bp K562 MPRA set, max Smith-Waterman scores across chromosome-split sets far exceed dinucleotide-shuffled controls; \~half the elements overlap repeats. Test performance of DREAM-CNN/RNN/Attn and MPRAnn rises with similarity to training sequences, and a nearest-neighbour heuristic (OverfitNN, k=10) scores well, so memorization alone suffices. GWAS SNV doppelgängers — identical alternate-allele sequences elsewhere in the genome — make variant-effect evaluation reward memorization. Tool: hashFrag, a BLASTn shortlist (word\_size 7, E-value 100, dust off, max\_target\_seqs = dataset size) then Smith-Waterman rescoring (match +1, mismatch −1, gap open −2, extend −1), homolog threshold SW ≥ 60, chosen to exceed shuffled-sequence scores; recall 99.99%, FPR \~0.17%; 86–161× faster than all-pairs. Recommended split: build a graph with homology as edges and assign connected components wholesale to train/val/test, 80/20. States no threshold is definitively correct and that strict thresholds can remove convergently evolved elements such as CTCF sites.

**Cross-property holdout.** [Badrinarayanan et al.](https://arxiv.org/html/2510.20943v1) hold out one property type (functional fitness, ΔTm, ΔS, ddG) and meta-train on the others — a generalization axis distinct from cross-protein.
